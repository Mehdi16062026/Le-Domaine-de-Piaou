# Bordeaux Étanchéité

Site vitrine statique pour une société d'étanchéité basée à Bordeaux.

## Pages
- `index.html` : page d'accueil avec présentation de l'entreprise
- `services.html` : description des principales prestations
- `realisations.html` : galerie de quelques chantiers
- `contact.html` : formulaire et coordonnées de contact

## Utilisation

Ouvrir `index.html` dans un navigateur pour afficher le site.
